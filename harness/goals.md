# 프로젝트 목표

## 제품 목표

Cloud Application Guide는 클라우드 애플리케이션의 기본 흐름을 학습·검증하기 위한 작은 주문 시스템이다.

- 회원이 로그인하고 상품을 조회할 수 있어야 한다.
- 상품과 재고를 등록·조회할 수 있어야 한다.
- 회원이 재고 범위 안에서 상품을 주문할 수 있어야 한다.
- 주문을 조회하고 `ORDERED` 상태의 주문을 취소할 수 있어야 한다.
- API와 Thymeleaf 화면의 계약이 일관되어야 한다.

## 엔지니어링 목표

- 변경은 작고 검증 가능해야 한다.
- 재고와 주문의 상태 변경은 원자적으로 처리되어야 한다.
- 공통 UI와 도메인별 UI를 분리해 확장성을 유지해야 한다.
- 모든 변경은 자동화된 품질 게이트로 재현 가능하게 검증해야 한다.

## 범위 밖

현재 범위에는 결제, 배송, 관리자 권한, 비밀번호 암호화·재설정, 외부 메시지 발송, 고급 검색·페이징이 포함되지 않는다. 해당 기능은 별도 설계와 합의 없이 추가하지 않는다.
